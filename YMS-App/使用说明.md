# Mini-YMS v1.0.0 · 使用说明

> **Yield Management System** —— 半导体良率数据分析工具（离线免安装版）
> 版本 **v1.0.0**（首个正式发布版）· 双击 `index.html` 即可使用，无需安装 Python / Node / 数据库，无需联网。

---

## 一、快速开始

| 步骤 | 操作 |
|---|---|
| 1 | 解压 `Mini-YMS-v1.0.0.zip`（任意目录，路径建议不含中文以外的特殊字符） |
| 2 | 双击 `index.html`（推荐 Edge / Chrome） |
| 3 | **Data → Data Import** 选择包内 `sample/sample_yield_data.csv` 示例（6000 行），或导入自己的数据 |

> 全部计算都在本机浏览器内存中完成，**数据不上传、不外发**。

- **左列**：第一行菜单区，第二行快捷方式区，第三行工作区（数据视图 / 绘图视图）。

  例外：**X 轴旋转** 与 **分组配色**（设置区「6 · 多数据同图 / 多 Y 轴 → 分组配色」）改完立即生效，无需 Submit。

## 三、Data 菜单

### 1. Data Import — 导入数据
支持格式：

| 格式 | 说明 |
|---|---|
| `.csv` / `.txt` | 自动识别分隔符（`,` `;` `Tab` `\|`）、UTF-8 BOM、引号包裹与字段内换行；**流式分块解析**，百万行也不卡界面 |
| `.xlsx` / `.xls` | 读取第一个工作表（SheetJS 内置）；Excel 日期单元格自动识别为时间列 |
| `.yms` | YMS 专用模板：**自动恢复数据 + 数值格式 + 字体 + 多级排序 + 已配置好的绘图，并直接进入绘图区** |

导入后自动推断列类型：

- 数值列：**非空且非明确缺失**的值中 **>90% 可解析为数字** → `number`
  - 容错写法：`95%` → `0.95`、`1,234` / `1,234,567.89` → `1234` / `1234567.89`（严格千分位形态才去逗号）
  - 明确缺失：`N/A`、`NA`、`n.a.`、`-`、`—`、`null`、`NaN`、`Infinity`、空串/纯空白 —— 按缺失处理，既不计分子也不计分母
  - **显示保留原文**：单元格仍显示 `95%`，参与计算 / 统计 / 绘图 / 导出时用 `0.95`
- 时间列：非空值中 **>90% 匹配日期时间模式** → `time`（支持 `YYYY-MM-DD HH:MM:SS`、`YYYY/M/D`、`YYYYMMDD`、ISO、`HH:MM:SS`）
- 其余 → `char`（字符）

> 也可以直接把文件**拖到窗口内**导入。

> **空文件不会覆盖当前数据（M-3）**：0 字节 / 纯空行的 CSV、没有表头的工作表、空 `.yms` 模板会被判定为「没有可导入的数据（0 行 × 0 列）」→ 提示并**取消导入**，当前已载入的表原样保留（不覆盖、不清空处理说明）。
> 只有表头、0 行数据的文件仍会导入（用于先建结构），但提示语降级为「只有表头（仅列定义，0 行数据）」—— 看到这句就说明这张表里还没有数据行。

> **重复列名自动改名（M-4）**：表头出现同名时按出现顺序第 2 个起加后缀 —— `A,A,B` → `A / A_2 / B`、`A,A,A` → `A / A_2 / A_3`；已被占用的名字会避让（`A,A_2,A` → `A / A_2 / A_3`，不会撞成两个 `A_2`）。**只改列名、不动数据**；状态栏与「处理说明」写明改了哪几列（如 `A → A_2（第 2 列）`）。CSV / Excel / `.yms` 三条路径规则一致。重命名到已存在的列名会被拒绝并提示「列名「X」已存在，请换一个」。

### 2. Data Outport — 导出数据
弹出确认对话框，选择：

- **格式**：CSV（默认）/ Excel
- **范围**：视图全部（含预处理与排序后的结果）/ 当前页

导出内容首列为行号 `#`，数值按当前列的小数位格式输出。

### 3. Save Data — 保存当前数据
按 `表格名-时间戳.csv` 保存当前视图数据。

### 4. Save Data with Template — 保存 `.yms` 模板
把「**处理后的数据 + 表格格式 + 绘图配置**」保存为一个 `.yms` 文件。
下次 `Data Import` 选中它，即可**一键回到上次的工作状态**（数据、列类型、小数位、字体、多级排序、绘图配置、当前页签），省去二次处理。

> **模板会被校验（S-2）**：`.yms` 里的设置项只接受已知字段 —— 手改或损坏的模板**不会把界面弄崩**：不认识的字段**一律忽略**，类型或取值不合法的字段**回落默认值**，两种情况都会在「处理说明」与提示里写明（最多列 5 个键名，余下用「等」）。体量上限：**文件 > 32 MB / > 50 张表 / 单表 > 100 万行 / 合计 > 200 万行**的模板会被**拒绝载入**，当前已载入的表与绘图配置原样保留。

### 5. Report Export — 导出 PPT 报告
导出 **PPT（.pptx）** 报告，**按 Page 分页**：绘图区的每一页对应一张幻灯片，页内包含该页全部图表（排版与屏幕上显示的一致，同一套配色/坐标轴/拟合曲线）。

幻灯片结构：
1. **标题页** —— 数据文件、表格名、原始行×列、视图行数、生成时间、绘图配置摘要
2. **参数统计摘要页** —— 类型 / 有效值 / 缺失 / 唯一值 / Min / Max / Mean / Median / StdDev
3. **每个 Page 一页** —— 该页的全部分面图表（分面过多时自动拆页并标注 (1/2)）

> 报告完全离线生成（内置自写的 PPTX 写出器，零依赖），双击即可用 PowerPoint / WPS 打开，可直接用于评审与汇报。

## 四、数据视图

### 原始表格区（左）
显示表格名与全部参数（带类型徽标 `number` / `time` / `char`，有缺失值标注 `缺 N`）。

**在参数上点右键**，可用：

| 菜单项 | 功能 |
|---|---|
| **参数属性** | 类型、有效值、缺失、唯一值、Min / Max / Mean / Median / StdDev（标准差为总体标准差，分母 N） |
| **修改数据格式** | `char` / `int` / `float` / `time`。转 `time` 支持 Excel 序列号（如 45000 → 2023-03-15）、秒 / 毫秒时间戳、日期字符串，自动识别 |
| **数据计算（表达式新建列）** | 弹出**居中对话框**：多行表达式 + **新列名按表达式自动命名**（`round(Yield * 100, 2)` → `round(Yield)`，纯列运算 → `列名_计算`，重名自动 ` (2)`）+ **缺失值处理**（保留缺失 / 补齐为 0 / 补齐为 1）+ **可用列 chip** + **实时预览前 5 行** + 底部 **预览** 按钮 + **内嵌函数库**（横向 TAB，点函数插入、点列即作用到函数上）。详见下节「数据计算与表达式函数」 |
| **填充缺失值** | 均值 / 中位数 / 0 / 前一行 / 固定值 —— **直接写入数据**（填充后缺失计数归零） |
| **按本列去重** | 保留首次出现的行（缺失视为同一取值） |
| **重命名列** | 自动同步排序、筛选与绘图配置中的列名 |
| **删除列** | 二次确认后删除 |

### 数据计算与表达式函数

右键参数 →「**数据计算（表达式新建列）**」打开居中对话框：

| 区块 | 说明 |
|---|---|
| **表达式** | 多行等宽输入；`Ctrl + Enter` 等同「确定」 |
| **新列名** | **按表达式自动命名**：`函数名(第一个参数里的列名)` —— `round(Yield * 100, 2)` → `round(Yield)`、`abs(Idsat - 0.5)` → `abs(Idsat)`；无函数调用但有列 → `<列名>_计算`（`col('Measure Time')*2` → `Measure Time_计算`）；都没有 → `计算列`。重名自动 ` (2)` / ` (3)`。**手动改过就不再被覆盖**；清空后恢复自动（失焦或改表达式时补回） |
| **缺失值处理** | `保留缺失`（默认，该行留空）/ `补齐为 0` / `补齐为 1` |
| **可用列** | 当前表所有列名 chip，点一下插入到光标处；**若光标前是未闭合的函数调用（如 `round(`）→ 列名放进括号并自动补 `)`**，形成 `round(Yield)`；列名含空格 / 特殊字符时插入 `col('名称')`（虚线边框表示） |
| **实时预览** | 前 5 行计算结果，输入后 200ms 刷新；语法错误直接显示在预览区（不弹窗、不阻断编辑） |
| **预览按钮** | 底部左侧「预览」：空表达式 → toast「请先输入表达式」；语法错误 → 预览区红字 + toast「表达式有误：…」；合法 → 刷新前 5 行 + toast「预览：前 5 行计算完成」并高亮 300ms |
| **函数与语法（内嵌）** | 位于语法提示下方，横向 7 个 TAB（基础数学 / **语法 / 控制流** / 取整与舍入 / 幂与对数 / 三角函数 / Math 扩展 / 语法速查），每张卡片含函数名 · 用法 · 说明 · 示例；**单击函数名** → 表达式框出现 `f()` 且光标在括号内（有选中文本时包裹成 `f(选中)`；语句块卡片则整段插入模版）；TAB 支持 ← → 切换 |
| **确定 / 取消** | 确定后新增数值列并提示「新增列 X（n 行，缺失 m）」；`Esc` / 点遮罩 / 取消均关闭 |

**语法速查**

| 语法 | 写法 | 说明 |
|---|---|---|
| 列引用（标识符列） | `Yield` | 列名为字母/下划线/`$` 开头、不与内置函数同名 → 直接写 |
| 列引用（任意列） | `col('Measure Time')` | 列名含空格、中文、符号时使用；列不存在 → 缺失 |
| 算术 | `+ - * / % **` | `%` 取余，`**` 求幂 |
| 比较 | `> < >= <= === !==` | 结果是布尔值，要输出数值请用三元转成 1 / 0 |
| 逻辑 | `&& \|\| !` | 与 / 或 / 非 |
| 三元 | `Wafer > 10 ? 1 : 0` | 条件成立取前者 |
| 常量 | `Math.PI` / `Math.E` | 完整 `Math` 对象都可用 |
| 结果类型 | 必须能算出数值 | 非数值（文本 / 布尔 / NaN）按缺失计 |

**内置函数（16 个）**

| 函数 | 用法 | 说明 | 示例 |
|---|---|---|---|
| `abs` | `abs(x)` | 绝对值 | `abs(Vth - 1.2)` |
| `round` | `round(x, n)` | 四舍五入保留 n 位小数（n 省略 → 取整） | `round(Yield * 100, 2)` |
| `ceil` | `ceil(x)` | 向上取整 | `ceil(Yield * 10)` |
| `floor` | `floor(x)` | 向下取整 | `floor(Yield * 10)` |
| `sqrt` | `sqrt(x)` | 平方根；x 为负 → 缺失 | `sqrt(pow(Vth, 2) + pow(Idsat, 2))` |
| `log` | `log(x)` | 自然对数；x ≤ 0 → 缺失 | `log(Yield)` |
| `log10` | `log10(x)` | 常用对数；x ≤ 0 → 缺失 | `log10(Yield * 100)` |
| `exp` | `exp(x)` | e 的 x 次幂 | `exp(Vth)` |
| `pow` | `pow(x, y)` | x 的 y 次幂（也可 `x ** y`） | `pow(Vth, 2)` |
| `min` | `min(a, b, …)` | 最小值 | `min(Yield, Bin1)` |
| `max` | `max(a, b, …)` | 最大值 | `max(Yield, Bin1)` |
| `sign` | `sign(x)` | 符号（-1 / 0 / 1） | `sign(Vth - 1.2)` |
| `sin` | `sin(x)` | 正弦（弧度） | `sin(Math.PI / 4)` |
| `cos` | `cos(x)` | 余弦（弧度） | `cos(Math.PI / 3)` |
| `tan` | `tan(x)` | 正切（弧度） | `tan(Math.PI / 6)` |
| `atan` | `atan(x)` | 反正切（弧度） | `atan(Vth / Idsat)` |

**Math 常用**：`Math.hypot(a, b)`（平方和开方）、`Math.trunc(x)`（截断取整）、`Math.PI`、`Math.E`。

**缺失值语义**

- 列的缺失进入表达式后是 `NaN`，会沿运算传播 —— `Yield * 100` 遇缺失行，结果仍缺失。
- `log(0)`、`sqrt(-1)`、`0 / 0` 也得到 `NaN`，同样按缺失计。
- 「缺失值处理」决定结果列怎么写：保留缺失（留空）/ 补齐为 0 / 补齐为 1。

**语句块模式（迭代 24）**

表达式框除了写一条表达式，也可以**直接写语句块**（含 `return`、首词是语句关键字、或顶层出现 `;` 即自动切到语句块模式；纯表达式仍走原来的单表达式模式，行为完全不变）：

| 写法 | 示例 | 说明 |
|---|---|---|
| `if / else` | `if (Yield > 94) { return 1; } return 0;` | 命中 if 就返回它里面的值，否则走兜底 `return` |
| `for` | `let s = 0; for (let k = 0; k < 3; k++) { s += k; } return s;` → 3 | 三段与 JavaScript 完全一致 |
| `while` | `let k = 0; while (k < 4) { k++; } return k;` → 4 | 条件不成立时退出 |
| `let / const` | `let a = Vth * 2; const b = a + 1; return b;` | 多步计算，变量只在本次计算内有效 |
| `switch` | `switch (true) { case Yield > 95: return 2; default: return 0; }` | 多分支，命中第一个成立的 `case` |
| `return` | `let x = Vth * 2; return x;` | **必须写**：没写会报「语句块需要以 return 返回一个值」 |

- 块内可用 `__i`（0 基行号）、`__n`（总行数）；列值 / `Math` / `col()` / 16 个内置函数照常可用。
- 表达式级条件函数（**两种模式都能用**）：`iif(cond, a, b)`（`if` 是保留字，所以叫 `iif`）、`choose(idx, a, b, …)`（0 基取参，越界得缺失）、`coalesce(a, b, …)`（首个非缺失值）、`between(x, lo, hi)`（闭区间 → 1 / 0，`x` 缺失得缺失）。
- **死循环防护**：`while` / `for` 的条件里会插入迭代计数，单行超过 **20 万次**即中止并报「循环次数超限（可能存在死循环）」；另有时间预算（预览 1.5s / 确定 8s），超时报「表达式执行超时（可能存在死循环）」。错误显示在预览区 / toast，页面不会卡死。
- **安全拦截**：`window`、`document`、`localStorage`、`sessionStorage`、`fetch`、`XMLHttpRequest`、`eval`、`Function`、`require`、`import`、`globalThis`、`top`、`parent`、`self`、`postMessage`、`Worker`、`WebSocket` 一律静态拒绝（报「不允许访问 X」），表达式里只能访问列值、`Math`、`col()` 与上述函数。

**函数与语法（内嵌在对话框下方）**：横向 7 个 TAB，函数卡片与上表逐条对应（「语法 / 控制流」TAB 10 张卡：`if / else`、`for`、`while`、`let / const`、`switch`、`return`、`iif`、`coalesce`、`between`、`choose`）。**单击函数名** → 表达式框出现 `f()`（光标在括号内；有选中文本则包裹成 `f(选中)`；语句块卡片插入整段模版、光标在末尾）；**再单击可用列** → 列名落进该括号并自动补右括号。语法速查 TAB 里另有缺失值语义与 **6 条「填入」示例**（点一下整条写进表达式框）。右键菜单「数据计算」项右侧 **ⓘ** 直接打开本对话框并把函数库滚到可见、聚焦第一张卡片。

### 分组映射 · 按值分组（迭代 25 建功能 / 迭代 27 重做面板）

右键参数 →「**分组映射…**」：把该列的离散值归并成用户命名的组（例：Tool 的 T01~T04 → 清洗、T05~T08 → 沉积），产出一个**字符型派生列**（默认名 `<源列>_Group`，可改）。派生列就是普通的列 —— **直接当 X Label / Sorter / Page by / Split by / 颜色分组列**用，绘图侧不需要任何新通路。

**面板 = 左「值列表」+ 右「分组定义表」**：左栏勾选若干值 → 点「**+ 新增分组**」→ 右侧自动出现一行、`Group Parameter` 已填好所选值、光标落进 `Group Name` 输入框 → 打一个组名即可。12 个值分 4 组只需**打 4 次组名**（旧版逐行输入要打 10 次）。

| 区块 | 说明 |
|---|---|
| **源列** | 默认 = 右键的那一列；换源列会自动重新列出不同值并剪掉已不存在的取值 |
| **值列表（左）** | 自动列出该列全部不同值（去重：字符列按**首次出现顺序**、数值/时间列按**数值升序**）；每行一个**复选框** + 取值 + 「N 行」权重 + 已归属的组名标签。搜索框覆盖**全部**取值；`全选` / `清空` 只作用于当前（搜索后的）列表。**虚拟滚动**：1000+ 个取值也只渲染可视窗口那一屏 DOM |
| **Group Name（右表第一列）** | **手工输入**组名；改了即时生效（左栏归属标签跟着变），重名会红框 + 报错 |
| **Group Parameter（右表第二列）** | **下拉复选框**：点开列出全部取值（面板内还有搜索），勾选即归属本组；面板不随勾选关闭，方便连选 |
| **组顺序** | 表格行序 = 横轴类目顺序，**不是字母序、也不是出现序**；每行 `↑` `↓` 调整、`×` 删除（组内取值回到「未分配」）；表底还有一个 `+` 新建空分组 |
| **一个值只属于一个组** | 把已在别组的值勾进本组 → 自动从旧组移出，并在提示条写明「有值已从「清洗」移到第 2 组」；因此提交结果永远唯一、可预期 |
| **未分配值** | 没有被归组的取值二选一：`归为「未分组」`（**默认**，图上是一个独立类目，排在最后）/ `保留原值`（图上直接显示 `T11`、`T12` 这种原值，排在已知组之后） |
| **预览** | 底部「预览 · 前 5 行」：原值 → 组名，随改动实时刷新；`保留原值` 模式下原样显示原值 |
| **批量规则（可选）** | 展开后每行一条 `选择器=组名`：`T01=清洗`、`T01,T03=清洗`、`T01-T04=清洗`（区间按上面值列表的下标取，含两端）。规则按组名并入已有组，不会重复建组 |
| **确定 / 取消** | 确定后新列追加到当前表末尾、自动滚动到该列可见，提示与处理说明里写明「顺序 光刻 → 清洗 → 沉积 → 其他」；列名重名、有值没打组名（报第几个分组）、或一个组都没建时红字提示且不写数据。取消不产生任何列 |

**三条行为约定**

1. **横轴严格按组顺序**：用分组列作 X Label 时，横轴类目按 UI 里排的顺序；若同时配置了 **Sorter**，**Sorter 优先**（Sorter 是更明确的意图）。
2. **修改不新建列**：分组列再右键显示「**修改分组映射…**」，编辑后**原地更新**同一列（不会堆出 `Tool_Group (2)`）。
3. **派生列是快照**：分组结果按确定那一刻的源数据算出，**改源列数据不会自动重算**（重新打开面板点确定才重算）；源列被删除也不影响已生成的列。组顺序与映射随 `.yms` 保存/还原。

缺失值显示为空白。

### 表头筛选（迭代 23 · Excel 式下拉）

每个列表头右侧有一个 **▾** 按钮（`#` 行号列没有），点开就是该列的下拉筛选面板：

| 区域 | 说明 |
|---|---|
| 搜索框 | 子串匹配（不区分大小写），输入即筛（90ms 防抖）；回车立即生效，Esc 关闭不应用 |
| 全选 / 清空 | 无搜索时作用于该列**全部**取值；搜索中只作用于当前可见项 |
| 值列表 | 每行 `[复选框] 值 …… 计数`；**（空白）** 单独一项代表缺失值；按数据出现顺序排列；列表最多渲染 800 项，超出时底部提示「仅显示前 800 个值，请用搜索缩小范围」（搜索仍覆盖全部取值） |
| 底部 | **清除本列筛选**（该列无筛选时禁用）/ **取消** / **确定**（主色）。点面板外部、Esc、取消都**不应用** |

语义：

- **全部勾选 = 不筛选**：确定后该列不记录筛选，按钮回到非激活态。
- **多列之间是「且」（AND）**：同时限制，行数逐层收敛。
- 值清单基于**未应用表头筛选**的数据（右侧「条件筛选」/ 缺失处理 / 排序已生效），因此表头筛选是在它们之上的再一次快速过滤。
- **与右侧「条件筛选」各自独立**：表头筛选只影响数据显示区的显示，**不改数据、不写 `.yms`、不参与绘图与导出**；右侧条件筛选仍作用于数据处理链（绘图 / 导出都按它走）。
- 生效时：该列表头出现主色下边线、按钮变主色填充；数据显示区标题行显示 **共 N 行 · 筛选后 M 行**，状态栏显示 **表头筛选：M / N 行**；标题行右侧出现 **清除表头筛选** 一键清空全部列。
- 筛选后没有数据时显示「筛选后无数据」，仍可用「清除表头筛选」恢复。
- **重置时机**：切换表格 / 重新导入 / 删除表格会自动清空表头筛选（避免列名不匹配的脏筛选）；同一张表内数据内容变化（例如填充缺失值）时保留筛选。

> 10 万行实测：日期列 / 字符列打开面板分别约 50–100 ms（唯一值统计只扫一遍，按「表 + 列 + 数据版本」缓存），应用筛选重渲当前页约 35–100 ms。

### 分组配色（设置区「6 · 多数据同图 / 多 Y 轴 → 分组配色」）

- **什么时候有分组**：设置区选了「**颜色分组**」列 → 分组 = 该列的每个取值（同值同色）；没选颜色分组 → 分组 = 每条 **Value 系列**（列名）。分组按数据出现顺序排列，最多枚举 **40 组**（与渲染层分组上限一致）；面板用**一个下拉框**装下全部组（不再截断到前若干组，组数多也不撑高面板）。
- **怎么改色**：先在下拉里选「要改哪一组」（**切换只换编辑对象，不改任何颜色**），再点右侧**色块按钮** → 展开 **12 色预设**（点一下即用该色），展开条末尾的「自定义…」是**系统取色器**（任意颜色）。改动**立即生效**，不需要点 Submit。
- **恢复默认**：面板右上角「恢复默认」一键清空全部自定义色，回到默认调色板映射（无自定义时按钮为禁用态）。
- **作用范围**：Box（填充 = 该色 18% 透明、边框 = 该色）、Line / Bar（线色 / 柱色）、Scatter（点色）、Box 中位数连线、**图例**，以及横轴统计表的**行名文字色**都随该色。
- **保存**：配色随 `.yms` 模板一起保存（`plot.group.colors`），下次载入模板原样恢复；旧模板没有该字段时按 `{}` 处理（沿用调色板，不报错）。
- **不适用**：直方图为单系列固定色，不支持分组配色（面板会说明）；分组上限 40、符号分组 7 种循环、多 Y 轴轴位等既有行为不变。

### 防拥挤合并
X 类别过多时，**相邻类别自动合并为一组**；组标签只显示**该组的代表值**（组内第一个类别名，如 `L0064`），
不再拼 `L0064~L0096` 这种范围——标签变短后，同一张图能显示的标签更多（迭代 15）。
合并组的**完整范围不丢**：鼠标悬浮时 tooltip 头行给出「代表值（完整范围，类数）」，如 `L0064（L0064~L0096，27 类）`；
合并组的统计量按**组内全部原始数据重新计算**（不是对各组结果再平均），因此箱线图、均值都不会失真。
合并情况（如「合并：1049 → 39 组（每 27 类合并，上限 40）」）显示在页签 / 工作信息里；图内不重复显示。

### X 轴智能显示（抗拥挤）
- 类别数 ≤ 8 → 水平显示；9–20 → 旋转 45°；21–80 → 旋转 30°；> 80 → 旋转 30° + 按比例抽稀 + 自动隐藏重叠标签。
- 标签长度 > 8 字符 → **水平显示时**截断（完整内容见 tooltip）；**旋转显示时（30°/45°/60°/90°，含默认 90°）一律不截断** —— 长日期时间戳（如 `L101-2026-09-30 14:23:45`）整条完整显示，向下延伸占用的空间由底部留白自动加大提供（迭代 21）。迭代 15 起合并组标签用**代表值**（如 `L0064`），通常只有 4~6 字符；完整范围见 tooltip。
- **底部留白 = 统计行带 + 分组带 + 旋转标签块（相加，不是取大）**：`grid.bottom = 轴标签间距 + 统计行总高(行数×行高) + 行间距 + 分组带 + 标签块高(rotH) + 轴标题带`。自上而下依次是 **① 统计行 Mean/Std/Nu% → ② 分组带（级 0 在最上）→ ③ 旋转的类别标签**，故「统计行带顶边 = 绘图区下沿 + 轴标签间距」恒成立 —— 统计行不侵入绘图区、也不与标签/分组带重叠，三者都不会被容器底裁切。（早期版本把统计行排在标签块**下沿**，现已整块上移到绘图区下沿。）
- **不再「封顶裁字」**：旧版把留白卡在 280 / 400px，长标签 + 多统计行时统计行会被挤进标签块、底部越界被裁。现在改为按**容器实际可用高度**收敛：放不下时依次 ① 缩小标签字号（最低 9px）② 放宽绘图区下限 ③ 减少统计行 —— **任何一步都不裁标签**（宁可把绘图区向上压）。
- **全屏按实际高度重算**：放大视图用全屏容器的真实高度重算留白与行锚点（另加底部滑杆 30px 带），全屏比卡片更高时留白随之加大，绝不出现「卡片能放下、全屏反而重叠」。
- **X 轴标题默认居中显示在刻度下方**，锚点由「统计行带 + 分组带 + 标签块」的实际高度推出，永远落在最下方的类别标签之下；**Y 轴标题默认显示**（参数名），绘图区左边距按「**刻度数字实测宽度 + 标题宽度 + 间距**」自动加宽（迭代 15）——刻度是 `1.48` / `-1234.5` 这类长数字时，标题也不会被挤到画布边缘或压住刻度。

### Scatter 拟合
- 方法：线性 / 二次 / 三次 / 多项式 N 阶（2–8，**最小二乘正规方程 + 高斯消元列主元**）/ 指数 `y=ae^(bx)` / 对数 / 幂 `y=ax^b`。
- 拟合曲线以折线系列**叠加在同一张图**上，标题下方显示**拟合公式与 R²**。
- 散点数量超过 20 万时按步长抽稀显示（保证流畅），**拟合仍使用全部数据点**。

## 八、常见问题

**Q：双击 index.html 后表格/图表空白？**
A：请确认解压完整（`vendor/`、`js/`、`css/` 目录齐全），并使用 Edge / Chrome 打开。

**Q：能不能放到共享盘/网页服务器？**
A：可以，本应用是纯静态页面；但设计目标是**本机离线**使用，推荐直接双击打开。

**Q：为什么导入 Excel 几十万行很慢？**
A：Excel 文件需整体解析（SheetJS）。超大数据的推荐路径是**先另存为 CSV 再导入**（CSV 走流式解析，快得多）。

**Q：调整了绘图设置但图没变？**
A：绘图设置区改动需点 **Submit** 生效（快捷方式区的图型按钮例外，点击立即切换）。

**Q：设置了「预处理 - 删除含缺失的行」，为什么原始数据没变？**
A：预处理是**视图层**处理（不改原始数据，可随时切回「不处理」）。若要真正修改数据，请用参数右键菜单的「填充缺失值」。

## 十、多表管理与表格转换（迭代 14）

### 多表
- **多文件导入**：Data → Data Import 一次选多个文件，**每个文件生成一张表**（部分文件失败不影响其他表，失败清单会提示）。

| | 转置 | 可选某列作新表头 | `_T` |
| Combine | 纵向连接 | 多表按行拼接；**并集**补空 / **交集**只留共有列 | `_vcat` |
| | 横向连接 | 按行序号并排，或按公共键对齐 | `_hcat` |
| | 表连接 Join | 内(交集) / 左 / 右 / 外(并集)；多键；**默认空值不匹配**，可勾「空值视为相等」 | `_inner/_left/_right/_outer` |
| Column Ops | 分列 / 合并列 | 按分隔符拆列、多列合并为一列 | `_split` / `_merge` |
| Aggregate | 分组汇总 / 去重 | sum/mean/count/min/max/std/nunique；去重保留首/末 | `_agg` / `_dedup` |

- 每个面板结构：**参数 → 前 5 行预览 → 执行 / 取消**；参数非法时行内提示且面板不关闭。
- **名字默认值**：凡涉及变量名 / 参数名的输入统一默认 `Parameter`，涉及值名 / 数据名的统一默认 `Value`（目前只有逆透视「变量名 / 值名」两个输入框属于此类；其余操作的名字类字段都是「选择已有列」）。改名后**预览区表头立即跟随**，不需要先执行。
- 执行后：新表按后缀命名（重名再加 ` (2)`）→ 自动加入表格列表（紧跟父表缩进显示）并成为当前表；原表保持不变。
- 类型强转、丢列、多对多行数放大等会在执行后以警告提示（最多 3 条）。

## 图例色阶自动配色（迭代 26 新增）

绘图设置区「6 · 多数据同图 / 多 Y 轴 → 分组配色」区块顶部多了一行 **配色**：

| 元素 | 作用 |
|---|---|
| 预设下拉 | 10 套**离散定性色板**，默认 `Tableau 10`；括号里是该预设的类目上限 |
| 🎨 一键自动配色 | 按分组列表顺序，把本预设的颜色一次分配给当前全部图例（立即生效） |
| 色条预览 | 实时显示「当前图例数」会分到的颜色，鼠标悬停可看第几个图例对应哪个色值 |
| 超容量提示 | 仅当图例数 > 预设上限时出现，建议换更大的预设（如 Kelly 22 / Glasbey）；仍可应用，按「循环 + 明度分层」补齐 |

> 原先那行「参考数：N 个图例 / 本预设上限 M ✓ · 两两最小 ΔE2000 x.x」已按使用反馈**整行移除**（含超容量 ⚠ 分支），面板更紧凑；预设下拉、一键自动配色、色条预览与超容量提示全部保留。

- **手动改色完全保留**：一行里的色块（展开 12 色预设 / 系统取色器）、「恢复默认」行为一字未改。
- **自动会覆盖手改**：点一键配色时若检测到已手动调整过的颜色，会先弹确认「将覆盖已手动调整的 N 个图例颜色，继续？」。
- **超容量**：图例数超过预设上限时会多出一行提示（建议改用 Kelly 22 / Glasbey），此时仍可应用，颜色按「循环 + 明度分层」补齐（两两可辨度会下降）。
- **保存**：预设 id 与各图例颜色随 `.yms` 保存 / 还原。
- **没有连续渐变色阶**（viridis / plasma / Jet / rainbow）：图例是离散类目，连续色阶在类目数一多时相邻两项色差会跌破 ΔE2000 5（实测 Jet N=20 已 4.57、N=30 只有 2.79），读者分不清类目。

### 使用要点（v1.0.0）

- **两处设置都要点 `Submit` 才生效**（避免调参时反复重绘大数据）。例外：X 轴旋转、分组配色改完立即生效。
- **颜色只作用于图例显示层**（文字/背景/边框）；系列颜色仍走「一键自动配色 / 分组配色」。
- **横轴分组带的层级顺序** = 参数列顺序的逆序：设置区自上而下 `Tool_Group → Chamber_Group → Layer → Lot`，图上自上而下是 `统计行 → Lot → Layer → Chamber_Group → Tool_Group`。
- **全屏后可拖动底部滑块缩放**，缩放时箱体、统计值、参数行、分组带会同步重算。
- **数据不上传**：全部计算在本机浏览器内存完成。
