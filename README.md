# Mini-YMS

**离线良率数据分析工具** · Yield Management System
纯前端单页应用，双击 `YMS-App/index.html` 即可使用 —— 无需安装 Python / Node / 数据库，**无需联网**。

> v1.0.0 · 全部计算在本机浏览器内存中完成，**数据不上传、不外发**。

---

## 功能

| 模块 | 说明 |
|---|---|
| **数据导入** | CSV / Excel（xlsx）。容错解析：`95%` → 0.95、`1,234` → 1234、`N/A`·`-` → 缺失；表格仍显示原文 |
| **六种视图** | Table（数据表格）· Scatter · Line · Hist · Bar · Box |
| **分组** | 按值分组映射、N 级横轴分组带（自动合并相邻同类）、防拥挤合并 |
| **配色** | 10 套离散定性高对比预设（CIEDE2000 量化，N=10 最小 ΔE ≥ 5）+ 一键自动配色 + 分组配色 |
| **横轴统计行** | Mean / Median / Std / RNG / Nu% / n / Min / Max / Q1 / Q3，可旋转，支持表格方框 |
| **参数行** | X 轴多列时逐级展开分组带（自下而上 = X 列顺序，叶级紧贴统计行） |
| **全屏与缩放** | 双击图表放大；X 轴缩放时箱体 / 统计值 / 参数行 / 分组带同步重算 |
| **图例与图元** | 图例位置 / 排列 / 字号 / 图标尺寸 / 间距 / 背景 / 边框；各图型图元样式（箱宽、柱宽圆角、线宽线型、点大小形状透明度） |
| **模板** | `.yms` 模板保存 / 载入（键白名单 + 逐字段类型校验） |
| **导出** | CSV / Excel / PNG，CSV 公式注入防护 |

## 快速开始

```
1. 下载仓库（或解压发布包）
2. 双击 YMS-App/index.html        # 推荐 Edge / Chrome
3. Data → Data Import             # 选 YMS-App/sample/sample_yield_data.csv（6000 行示例）
```

**两处设置都要点 `Submit` 才生效**（有意设计：避免调参时反复重绘大数据）。
例外：X 轴旋转、分组配色改完立即生效。

## 设计要点

1. **单一几何源** —— 横轴表格的列心是唯一真源，箱体、统计文字、分组带全部对齐到它。
2. **默认零变化** —— 新增设置项的默认值逐项等于历史写死的值，老图视觉不变。
3. **离线优先** —— 无构建步骤、无 CDN、无后端；所有依赖本体内置在 `vendor/`。
4. **数值容错与原值分离** —— 参与计算用解析值，表格显示保留原文。

## 仓库说明

本仓库只包含**运行所必需的最小信息**：

| 已包含 | 未包含（有意排除） |
|---|---|
| 应用源码（HTML / CSS / JS）| 自动化测试用例与夹具（`YMS-App/test/`）|
| 离线依赖（`vendor/`）| 10 万行大示例数据集（9 MB，非运行必需）|
| 6000 行示例数据 | 打包产物 `.zip`、历史备份目录 `build/bak_*` |
| 打包脚本、用户手册 | 应用运行期自动生成的时间戳备份文件 |

需要完整发布包（含 10 万行数据集）时，在本地把该文件放回 `YMS-App/sample/` 后执行：

```bash
python build/package.py
```
